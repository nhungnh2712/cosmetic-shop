# GlowShop - Web Bán Mỹ Phẩm

## Cách chạy

### Bước 1: Cài thư viện
```
npm install
```

### Bước 2: Chạy server
```
node server.js
```

### Bước 3: Mở trình duyệt
```
http://localhost:3000
```

## Tài khoản mặc định
- **Admin:** admin@gmail.com / admin123
- **User:** Tự đăng ký tại /register.html

## Tính năng
- Trang chủ hiển thị sản phẩm
- Trang danh sách sản phẩm với tìm kiếm & lọc
- Trang chi tiết sản phẩm
- Giỏ hàng
- Thanh toán (checkout)
- Đăng nhập / Đăng ký
- Xem đơn hàng của tôi
- Trang Admin: Dashboard, quản lý sản phẩm, quản lý đơn hàng
